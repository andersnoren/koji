== Testing Tools and Methodology ==

Koji was originally updated to be accessibility ready in December 2018, after its initial release in September that same year. Testing has been done manually, with the help of tools like HeadingsMap (for checking heading levels) and Stark (for checking accessible color contrasts).

The theme was updated again in June 2026 to meet the updated accessibility requirements. That's also when this file was added.
